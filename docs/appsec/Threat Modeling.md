# Threat Modeling
## How to threat model?
1. Define security requirements for the entire application.
2. Write Security User stories
3. Identify threats in user stories
4. Mitigate threats from user stories, i.e.,  developer training, SAST/DAST.. 
6. Validate the threats are mitigated.
